# Villager Orders (Forge 1.20.1)

A small Forge mod for Minecraft Java Edition. Right-click a villager to open a command panel showing the villager's name and health.

Commands:
- **Follow Me** — follow the player who issued the command.
- **Stay Here** — stop wandering and remain in place.
- **Hide From Monsters** — seek a nearby covered position when hostile monsters approach; flee away if no suitable covered position is found.
- **Resume Normal Behavior** — clear the temporary command and let the villager's normal AI take over again.

Controls:
- Right-click: open the command panel.
- Shift + right-click: use the vanilla trading interaction.

Requirements: Minecraft 1.20.1, Forge 47.2.0+, Java 17.

See [README_AR.md](README_AR.md) for Windows 11 build and installation instructions.
